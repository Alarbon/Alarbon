## 🚀 Proyectos principales

### 🛒 Nuestra Compra
Listas de la compra personales y compartidas para Android y web (PWA). Cada cuenta tiene un espacio privado y puede unirse a grupos con sus propias listas, supermercados, despensa e historial. Incluye modo local sin cuenta, invitaciones por enlace y reglas de Firestore con pruebas automatizadas.

**Flutter · Riverpod · Firebase Auth · Cloud Firestore · Hive**

> **Estado:** beta web disponible. La versión Android se está preparando para Google Play y aún no está publicada.

[Probar la beta web](https://nuestracompra.web.app) · [Presentación](https://nuestracompra.web.app/descubre.html) · código privado

### 💧 Awita
App para encontrar, valorar y reportar fuentes públicas de agua potable. Une los datos abiertos de OpenStreetMap con las aportaciones de los usuarios, que pasan por moderación con roles comprobados en el servidor.

**Flutter · Supabase · PostgreSQL · MapLibre · OpenStreetMap**

> **Estado:** MVP en desarrollo. Código privado.

## 🧩 Proyectos públicos

**[bot_opos](https://github.com/Alarbon/bot_opos)**: revisa a diario los boletines oficiales (BOE, BOJA, BOP de Jaén), detecta convocatorias de informática y avisa por Telegram. Tiene histórico en SQLite, tests y ejecución con GitHub Actions.
`Python` `SQLite` `GitHub Actions` `Cloudflare Workers`

**[spring-dynamodb-api](https://github.com/Alarbon/spring-dynamodb-api)**: API REST de productos con Spring Boot 3 y Java 21 sobre DynamoDB Local en Docker, con arquitectura hexagonal.
`Java` `Spring Boot` `DynamoDB` `Docker`

**[BotFichajeTelegram](https://github.com/Alarbon/BotFichajeTelegram)**: bot para fichar la entrada, las pausas y la salida, y calcular el saldo de horas. Guarda los datos en Firestore.
`Python` `Telegram` `Firestore`

**[escucha_tu_historia](https://github.com/Alarbon/escucha_tu_historia)**: app Flutter con rutas y monumentos de Martos y el audio de cada punto.
`Flutter` `Dart`

**[crud-cassandra-spring](https://github.com/Alarbon/crud-cassandra-spring)**: guía paso a paso y API CRUD con Spring Boot y Apache Cassandra en Docker.
`Java` `Spring Boot` `Cassandra`

**[Pokemon_Next](https://github.com/Alarbon/Pokemon_Next)**: Pokédex web con Next.js y Tailwind CSS. [Ver demo](https://pokemon-next-one-lac.vercel.app)
`Next.js` `TypeScript` `Tailwind CSS`
